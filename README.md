# Erika Mena | Portfolio

Portafolio profesional de Erika Mena, Desarrolladora Full Stack JavaScript Junior.

El proyecto presenta mi perfil profesional, formación, habilidades técnicas, servicios, proyectos desarrollados y conocimientos en desarrollo web, WordPress y contenido digital.

## Demo

[Ver portafolio](https://portfolio-ashy-xi-32.vercel.app/)

## Tecnologías utilizadas

- React 19
- JavaScript
- Vite
- CSS
- Lucide React
- ESLint

## Características

- Diseño responsive para diferentes tamaños de pantalla.
- Navegación por secciones.
- Menú responsive para dispositivos móviles.
- Presentación de servicios y habilidades técnicas.
- Sección de proyectos con enlaces a los proyectos publicados.
- Formulario de contacto integrado con Formspree.
- Enlaces directos a WhatsApp, LinkedIn y GitHub.
- SEO básico mediante título, meta description y etiquetas Open Graph.

Instalación y ejecución
1. Clonar el repositorio
git clone https://github.com/ErikaMenawebdev/portfolio.git

2. Entrar al proyecto
cd portfolio

3. Instalar dependencias
npm install

4. Ejecutar en desarrollo
npm run dev

La aplicación estará disponible en la URL indicada por Vite.

5. Generar la versión de producción
npm run build

6. Ejecutar una vista previa de producción
npm run preview

7. Ejecutar ESLint
npm run lint
